白日梦AI生成库 · 使用说明

一份带你从「看提示词」到「用提示词」的保姆级指南，照着做就能上手。

1这是什么

白日梦AI生成库是一个开放的 AI 提示词（Prompt）库，把大家日常在用的优质提示词整理到一起，分成图片、视频、文本三类，全部可看、可复制、可自由使用。

这里没有登录、没有付费、没有解锁门槛——你看到的每一条提示词，点开就能复制走。站点每天实时刷新，常看常新。

它解决的是一个很实际的问题：自己从头写提示词又慢又难出效果，而别人跑通的好提示词，抄过来改改就能用。这个库，就是帮你把「好提示词」攒起来、翻出来。

2三块内容分别怎么用

🖼️

灵感画廊（图片提示词）

卡片式浏览，每张卡是一段图片提示词。点开看完整提示词，如果这条带风格参考图，也会一并展示。适合找画面灵感、对齐风格、抄作业。

🎬

视频提示词

视频类的提示词，很多带原声样片，点开卡片能直接看画面、听原声（动作 / 口播 / 音乐MV 等分类带原声；热门视频是 AI 生成的静音画面，本身没有声音）。

📝

文本提示词

文字类的创作提示词，比如文案、脚本、角色设定等。点开复制即用，直接给大模型当指令。

3基本操作（照着点就行）

①
搜索
顶部输入框，输入画面、场景、关键词，例如「电影感 / 口播 / 产品展示 / 分镜」，回车或点「搜一下」。
②
按分类筛
视频页、画廊都有分类标签，点一下快速定位你想要的风格，不用在一堆里瞎翻。
③
只看风格参考
画廊可勾选「✦ 只看风格参考」，只显示带参考图的条目，找画面灵感更高效。
④
语言 / 排序
可在「全部 / 中文 / English」间切换；排序支持「默认 / 最详细 / 最精简」，按需挑长度。
⑤
复制全文
点开任意卡片，点「复制全文」按钮，提示词就进剪贴板了，去你的工具里粘贴即可。
⑥
视频原声
视频页右上角有「自动播放」开关，开启后视频滚进画面自动静音循环；想听原声，点开卡片即可，右下角有「声音」按钮可一键开关。

4拿到提示词，怎么真正用起来

提示词不是看完就完了，得落到工具里才算数。按类型对号入座：

  • 图片提示词 → 复制到 即梦 / 可灵 / Midjourney / Stable Diffusion / SDXL 等文生图工具里生成画面。
  • 视频提示词 → 复制到 可灵 / 即梦 / Runway / Seedance 等图生视频 / 文生视频工具里出片。
  • 文本提示词 → 直接发给对话式大模型（如各类 AI 助手）当指令，让它按你的要求产出内容。

记住一句：提示词是「起点」不是「终点」。别人的好提示词拿过来，可以微调风格词、画面比例、镜头、主体人物，多试两三版，找到自己的手感。库里的提示词，是你练手的弹药库。

5常见问题

点开视频没声音？
「热门视频」是 AI 生成的静音画面，文件里本来就没有音轨，所以放不出声；想听原声，切到「动作 / 口播 / 音乐MV」等分类，卡片右下角有 🔊 标记的就是带原声的，点开即播。
图片打不开 / 封面是空的？
个别条目本身就没有配图，属正常；若大范围封面打不开，刷新一下页面通常就好。
数据多久更新一次？
站点每天实时刷新，新的好提示词会持续进库，建议常来翻翻。
这些提示词能商用吗？
站内提示词均为开放内容，可自由查看、复制与使用；具体商用请结合自身使用场景自行判断。
